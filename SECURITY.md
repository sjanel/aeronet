# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please email <dev.sjanel@gmail.com>. Do not open public issues for security concerns.

## Out of Scope

32-bit targets are not supported (aeronet does not build for them): reports that only affect a 32-bit build are out of scope.
